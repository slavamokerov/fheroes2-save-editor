fheroes2 Save Editor

A graphical save-file editor for the fheroes2 engine — the open-source reimplementation of Heroes of Might and Magic II. Runs right in your browser, no installation required.

Web Editor

Open an fheroes2 save (*.sav, *.savc, *.savm, *.savh), edit your heroes and download the result.

FAQ

Is my save file uploaded anywhere?

No. The web editor runs entirely in your browser and never sends the file anywhere.

Where are my fheroes2 saves?

macOS — ~/Library/Application Support/fheroes2/files/save; Windows — %LOCALAPPDATA%\fheroes2\files\save; Linux — ~/.local/share/fheroes2/files/save.

Why did my changes disappear?

If fheroes2 is running, AUTOSAVE can overwrite your edits. Close fheroes2 or edit a copy of the save.

Which save formats are supported?

*.sav, *.savc, *.savm, *.savh (fheroes2 save versions 10032–10034).
