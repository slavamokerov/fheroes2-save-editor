fheroes2 Save Editor

A graphical save-file editor for the fheroes2 engine — the open-source reimplementation of Heroes of Might and Magic II. Runs right in your browser, no installation required.

Web Editor

Open an fheroes2 save (*.sav, *.savc, *.savm, *.savh), edit your heroes and download the result.

Download

Prebuilt desktop builds for every platform:

Download for macOS (Apple Silicon) Download for macOS (Intel) Download for Windows x64 Download for Linux x64 (AppImage)

The desktop editor reads HEROES2.AGG from your fheroes2 data folder — no game files are distributed with this project. Sources and older releases are on GitHub.
