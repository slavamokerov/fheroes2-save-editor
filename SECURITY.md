# Security Policy

## Reporting a vulnerability

The editor works on your own save files — there is no server, and neither the
web nor the desktop version transmits data anywhere. Still, if you find
something that looks like a security issue (malformed save crashes, memory
bugs, etc.), please report it:

- **Preferably privately** via a
  [security advisory](https://github.com/slavamokerov/fheroes2-save-editor/security/advisories/new)
  if the issue could be exploited.
- Or open a regular
  [issue](https://github.com/slavamokerov/fheroes2-save-editor/issues) — for
  anything that does not need to stay confidential.

There is no formal SLA or bounty program; reports are handled on a best-effort
basis by the maintainer.
